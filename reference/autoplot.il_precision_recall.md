# Plot Precision–Recall Curve

Draws a precision–recall curve from the data produced by
[`il_precision_recall()`](http://christophertkenny.com/irelink/reference/il_precision_recall.md).

## Usage

``` r
# S3 method for class 'il_precision_recall'
autoplot(object, ...)
```

## Arguments

- object:

  An `il_precision_recall` tibble.

- ...:

  Additional arguments (currently unused).

## Value

A `ggplot` object.
