# Plot Blocking Rule Pair Counts

Draws a horizontal bar chart of candidate pairs generated by each
blocking rule, from data produced by
[`il_count_pairs()`](http://christophertkenny.com/irelink/reference/il_count_pairs.md).

## Usage

``` r
# S3 method for class 'il_count_pairs'
autoplot(object, ...)
```

## Arguments

- object:

  An `il_count_pairs` tibble.

- ...:

  Additional arguments (currently unused).

## Value

A `ggplot` object.
